Logistics Performance & Operations Dashboard
1. Project Title
Project Title: Logistics Performance & Operations Dashboard
An Interactive Logistics Performance & Operations Analytics Dashboard.

2. Short Description
-The Logistics Performance Dashboard is an interactive Power BI project designed to monitor and analyze logistics operations across orders, hubs, drivers, and vehicles. It provides insights into delivery performance, customer satisfaction, hub capacity, driver efficiency, and vehicle utilization.

-The dashboard helps management track key performance indicators (KPIs), identify areas for improvement, monitor business trends, and make data-driven decisions to improve overall logistics efficiency.

3. Tech Stack
- Power BI: Dashboard development and interactive data visualization.
- Microsoft Excel: Data cleaning, preprocessing, and initial data management.
- Power Query: Data transformation and data cleaning.
- DAX: Creating calculated measures, KPIs, MoM comparisons, and performance metrics.
  
4. Data Source
Dataset: Logistics Operations Dataset

5. Features & Highlights

A. Business Problem
Logistics operations involve multiple factors, including order volumes, delivery timelines, hub capacity, driver performance, and vehicle maintenance. Managing these activities separately makes it difficult to identify delivery delays, monitor operational efficiency, and evaluate overall business performance.

The business needs a centralized dashboard to track performance, identify areas of improvement, and support data-driven decision-making.
B. Project Goals
- Monitor overall logistics performance through interactive KPIs.
- Track monthly order growth and delivery efficiency.
- Evaluate hub capacity and order processing performance.
- Analyze driver experience, ratings, and delivery delays.
- Monitor vehicle utilization and breakdown patterns.
- Improve delivery and operational efficiency through data-driven insights.

C. Dashboard Overview & Key Visuals
1. Overview Dashboard
- Total Orders, On-Time Delivery Rate, CSAT, and Average Delivery Time.
- Previous Month comparison and Month-over-Month (MoM) analysis.
- Hub, Driver, and Vehicle performance summaries.
2. Hubs Overview
- Total Number of Hubs (KPI Card).
- Orders Processed vs Hub Capacity (Clustered Column Chart).
- Hub Performance Ranking (Ranked Bar Chart).
- Daily Hub Order Processing Time (Matrix).
3. Drivers Overview
- Total Number of Drivers (KPI Card).
- Experience vs Rating (Scatter Plot).
- Drivers with Most Delays (Bar Chart).
- Driver Profile Summary (Hire Date, Experience, Rating, Monthly Deliveries).
- Monthly Order Trends (Line Chart).
4. Vehicle Overview
- Total Number of Vehicles (KPI Card).
- Active vs Inactive Vehicles (Donut Chart).
- Orders by Vehicle Model (Bar Chart).
- Vehicle Age vs Breakdowns (Scatter Chart).
- Breakdowns by Vehicle Code and Model (Bar Charts).
- Orders by Vehicle Type (Donut Chart).
  
D. Business Impact & Insights
The dashboard enables management to:
1. Improve Delivery Performance: Monitor on-time delivery rates and average delivery duration to identify delivery inefficiencies.
2. Optimize Hub Operations: Compare processed orders against hub capacity to identify overloaded or underutilized hubs.
3. Enhance Driver Performance: Identify drivers with frequent delays and analyze the relationship between experience and ratings.
4. Improve Vehicle Management: Track active vehicles, order distribution, and breakdown frequency to support better vehicle utilization.
5. Monitor Customer Satisfaction: Analyze monthly CSAT performance and identify changes in customer experience.

E. Key Business Insights
The dashboard helps answer important business questions:
- Are total orders increasing or decreasing compared to the previous month?
- Is the on-time delivery rate improving?
- Which hubs are processing the most orders relative to their capacity?
- Which drivers have the highest number of delivery delays?
- Which vehicle models handle the highest order volumes?
- Are older vehicles experiencing more breakdowns?
